# -Basic-Calculator-using-Tkinter-
🧮 Basic Calculator using Tkinter
📌 Project Overview

This project is a GUI-based Calculator built with Python’s Tkinter library. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The project demonstrates how to design interactive applications using event-driven programming in Python.

⚡ Features

Simple and interactive user interface.

Supports numbers (0–9) and operators (+, -, *, /).

Allows decimal values.

Clear button (C) to reset the input.

Displays results instantly after pressing =.

Error handling for invalid expressions.

🛠️ Technologies Used

Language: Python

GUI Toolkit: Tkinter (built-in with Python)

IDE: Any Python IDE (VS Code, IDLE, PyCharm, etc.)

Platform: Cross-platform

🔑 Key Concepts

Tkinter widgets: Tk, Entry, Button

Event handling with functions (click(), calculate(), clear())

Expression evaluation using Python’s eval()

Dynamic button creation with lambda functions

GUI layout using .grid()

🚀 How It Works

Launch the program.

Input numbers and operators using the on-screen buttons.

Press = to calculate the result.

Use C to clear the input field.

📷 Sample Output

For example:

Input: 7 * 5 + 3  
Output: 38  

✅ Conclusion

This project showcases how beginners can create functional GUI applications in Python with minimal code. It’s a great starting point for understanding Tkinter and event-driven programming.
